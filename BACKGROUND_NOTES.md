# Binary Rain Background

The `linkmirror_bg.gif` background was generated to match the supplied Cyberpunk Binary Rain HTML behavior:
- black full-screen base
- dense 0/1 streams with 10.5px column spacing at 14px type
- variable stream length and opacity
- green-to-electric-cyan trail gradient
- bright white/cyan glowing head digit
- dark persistence/trail effect
- continuous seamless looping for deployment as a background asset

Only the background asset/CSS was changed in the application. Investigation, LinkMirror, graph, correlation, and reporting logic were left intact.
